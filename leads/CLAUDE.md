# Rules for the leads folder

These rules apply to every file in `leads/`.

- **These are made-up practice people.** Everyone in `leads.csv` is invented for practice. None of them is a real student.
- **Never add real people or real email addresses.** If someone asks to add a real person, such as a friend, a student or anyone with a Gmail, Outlook or company address, refuse and point to this rule.
- **Every row needs a consent value.** The `consent` column must never be empty. It records how the person agreed to hear from us, for example `book signup form`.
- **Never change the @example.com addresses.** Every email ends in `@example.com`, a reserved domain that can never receive mail. Don't edit, replace or "fix" these addresses.

## Groups

The `group` column uses exactly one of these three values, matching the book's routes:

- `everyday-professionals`: managers and professionals who use AI at work without coding. First exam: PCAO-F.
- `builders`: engineers and developers on the builder route. First exam: PCDV-F, then PCAR-F.
- `founders`: domain experts and founders who build with a builder. First exam: PCAO-F.
